# 处理旧记录与文件占用

顶部“执行结果需要核实”提示可以点击“不再提醒”，也可在运行详情选择“标记已处理”。处理提醒保留原始执行结果，不将“待核实”改成成功。需要重新关注时选择“恢复提醒”。正在运行或等待回答的任务不能用此操作隐藏。

运行详情提供“删除记录”。删除后记录和对应顶部提示从默认列表移走；勾选“已删除记录”可以查看并恢复。删除不会移除项目文件、客户端对话、前置任务引用或验收证据，也不会释放文件保护。

运行列表可勾选多条记录，或选择“全选已结束记录”，再“删除所选”。全选遵守当前搜索条件，跳过正在运行和等待回答的记录；后台也会逐条检查，一条不满足条件则整批不修改。在“已删除记录”中可批量恢复。

任务督导同样提供单条删除、勾选批量删除和“已删除任务”恢复。删除会暂停该任务尚未发送的指令，保留原验收结论和文件保护；恢复不会自动发送指令。运行中或正在收集验收证据的督导不能删除。

文件占用有独立的处理入口：在受阻任务旁点击“处理文件占用”，或打开“任务督导 → 文件占用与保护范围”。这里显示来源任务、状态、路径和保留时间。选择“核实并释放占用”后，后台检查对应原会话为空闲，并拒绝释放仍在运行或验收的任务。释放会暂停旧督导并保留原验收结果；队列中等待该范围的其他任务可能开始执行。

“登录后自动启动”只写入当前 Windows 用户 Run 项中的 `LocalAgentScheduler` 值；重复开启不会重新创建或覆盖整个 Run 项。关闭只移除该值，其他程序的启动设置不受影响。启动命令通过 `background.vbs` 隐藏运行当前安装目录的后台。
